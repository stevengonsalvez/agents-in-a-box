## P9.1 — gh CLI integration + PR URL capture

**Bead:** `hangar:P9.1 gh capture + task.result.pr_url`
**Owner:** ainb-hangar-daemon supervisor module
**Touches:** `crates/ainb-hangar-daemon/src/supervisor/`, `crates/ainb-hangar-store/migrations/`, `crates/ainb-hangar-core/src/result.rs`

### Why

Agents already shell out to whatever they want inside their worktree. v1 contract: if the agent ran `gh pr create`, capture the PR URL into `agent_task_queue.result` JSON so TUI can surface it. No GitHub App, no webhook. `gh` CLI fallback only per locked decision.

### RED — tests first

1. **Unit (`crates/ainb-hangar-core/tests/pr_url_parse.rs`):**
   - `parse_gh_pr_create_stdout(s)` returns `Some(url)` for canonical gh output `https://github.com/owner/repo/pull/123\n`
   - returns `Some(url)` for output with trailing log lines around URL
   - returns `None` for non-PR-URL gh output (e.g. `gh pr list` table)
   - parametrised via `rstest` over 5+ stdout fixtures captured from real `gh pr create` runs

2. **Integration (`crates/ainb-hangar-daemon/tests/tripwire_pr_capture.rs`) — TRIPWIRE 1:**
   - ephemeral SQLite + isolated `$HOME`
   - inject a fake-`gh` binary on `PATH` via tempdir that prints `https://github.com/test/repo/pull/42\n` then exits 0
   - spawn daemon, enqueue a task whose agent script is `gh pr create --title X --body Y`
   - poll `agent_task_queue` row until `status = completed`
   - assert `result->>'pr_url' = 'https://github.com/test/repo/pull/42'`

3. **Failure mode test:**
   - fake-`gh` exits non-zero → assert `pr_url` is `NULL` (not `""`), task status still completes if exit was non-fatal, fails otherwise

### GREEN — minimum impl

- migration `00N_task_pr_url.up.sql` — no schema change needed, `result` is already `JSON`. Document the JSON shape in `crates/ainb-hangar-core/src/result.rs`:
  ```
  TaskResult { pr_url: Option<String>, comment: Option<String>, exit_code: i32, ... }
  ```
- `core::pr_url::parse_gh_pr_create_stdout(&str) -> Option<String>` — regex `^https://github\.com/[^/]+/[^/]+/pull/\d+$` line-match
- supervisor captures full stdout into a ring buffer per task (cap 64 KB); on task complete scans for first PR URL line and writes into `result.pr_url` via a single `UPDATE agent_task_queue SET result = json_set(result, '$.pr_url', ?) WHERE id = ?`
- no env or config gating — always-on, free

### REFACTOR

- if more than one PR URL appears (multi-PR run), prefer **last** one written (most-recent intent); document
- ring buffer eviction policy: drop oldest line on overflow
- regex compiled once at startup via `once_cell::sync::Lazy`

### Acceptance

- [ ] tripwire 1 green
- [ ] `cargo test -p ainb-hangar-core -p ainb-hangar-daemon` green
- [ ] manual smoke: real `gh pr create` against a sandbox repo populates `pr_url`
- [ ] `clippy -D warnings` clean
- [ ] bead closed

## P9.2 — PR badge on Task detail + open-in-browser keybinding

**Bead:** `hangar:P9.2 PR badge + o keybinding`
**Owner:** hangar-tui plugin
**Touches:** `plugins/hangar-tui/ainb-plugin-hangar/src/screens/task_detail.rs`, `…/keymap.rs`, `crates/ainb-hangar-proto/src/wire.rs`

### Why

Capture without surface is invisible. Task detail must badge the PR URL and let user open it with one keystroke.

### RED — tests first

1. **Snapshot (`insta` on a width-aware buffer):**
   - render `TaskDetailScreen` for a `Task` with `result.pr_url = Some(...)` → assert PR badge cell present with gold text + truncated URL
   - render same task with `pr_url = None` → assert no badge cell (snapshot delta = removed line, not "PR: none" placeholder)
   - widths: 60 / 100 / 160 cols (caveman responsive)

2. **Integration (`plugins/hangar-tui/.../tests/tripwire_pr_badge.rs`) — TRIPWIRE 2:**
   - spawn `ainb hangar tui` inside tmux with seeded DB containing one completed task whose `result.pr_url = https://example.com/pr/1`
   - `tmux send-keys` to navigate to task detail
   - `tmux capture-pane -p` → assert substring `PR https://example.com/pr/1`
   - then `send-keys o Enter`
   - assert: a side-effect probe file was written by the mocked opener

3. **System opener mock:**
   - new trait `crate::shell::Opener { fn open(&self, url: &str) -> io::Result<()>; }` with two impls: `SystemOpener` (real `open`/`xdg-open`) + `RecordingOpener` (writes the URL to a path from `HANGAR_OPENER_PROBE_FILE` env)
   - tripwire flips env to `RecordingOpener` and asserts probe file contents == URL

### GREEN — minimum impl

- proto: `TaskView { …, pr_url: Option<String> }`
- task_detail render: if `pr_url.is_some()`, render single-row badge `▶ PR <url>` in gold. Truncate URL at width using `chars()` not bytes (`reference_rust_utf8_truncate_trap`)
- keymap: bind `o` to `Action::OpenPrUrl` only when current task has `pr_url`
- handler: call `Opener::open(url)`
- platform dispatch:
  ```rust
  #[cfg(target_os = "macos")] cmd = "open";
  #[cfg(target_os = "linux")] cmd = "xdg-open";
  ```
  Windows already excluded by `reference_rust_unix_only_apis`

### REFACTOR

- key binding hint renders next to PR badge, not in global help bar (`feedback_keybinding_hints_near_control`): show `[o] open` muted-gray to right of URL
- no `o` binding when `pr_url` is None — avoid silent no-op

### Acceptance

- [ ] tripwire 2 green
- [ ] insta snapshot delta reviewed + committed
- [ ] `o` keybind silent no-op suppressed when no URL
- [ ] manual: real `cargo run -- hangar tui` against seeded DB opens URL in host browser
- [ ] bead closed

## P9.3 — Full e2e tripwire pass + CI matrix (macOS arm64 + linux x86_64)

**Bead:** `hangar:P9.3 CI matrix + full e2e pass`
**Owner:** devops-automator + tech-lead-orchestrator
**Touches:** `.github/workflows/ci.yml`, `.github/workflows/release.yml`, possibly new `.github/workflows/hangar-e2e.yml`

### Why

Critical-path gate. Locks the platform contract before brew + release. All P0-P8 tripwires must run on both target OSes in a single `cargo test --workspace` invocation.

### RED — tests first

1. **CI definition test (`xtask/src/ci_lint.rs`):**
   - parse `.github/workflows/ci.yml` (and any new hangar-e2e workflow) and assert:
     - matrix contains both `aarch64-apple-darwin` (runner `macos-latest`) and `x86_64-unknown-linux-gnu` (runner `ubuntu-latest`)
     - test step invokes `cargo test --workspace --all-targets` (not narrow `-p` set)
     - tmux is installed before the test step on both runners
     - clippy step uses `-D warnings`
   - run via `cargo xtask ci-lint`; wired into PR check

2. **Local tripwire roll-up (`crates/ainb-hangar-daemon/tests/tripwire_full_e2e.rs`) — TRIPWIRE 3 (meta):**
   - `#[test]` that programmatically discovers every `tripwire_*` test in the workspace (via `cargo test --list -- --format=json`) and asserts the discovered set ≥ baseline count (P0–P9 expected count, hardcoded after first run per `feedback_dont_guess_test_constants`)
   - prevents silent tripwire deletion / rename

3. **Workspace tripwire green-bar:**
   - `bash scripts/hangar/run_all_tripwires.sh` script: invokes `cargo test --workspace --test 'tripwire_*' -- --test-threads=1` with `set -o pipefail` (`reference_tail_masks_pipe_exit`); exit code = sum
   - CI step runs the script; failure surfaces the failed tripwire name

### GREEN — minimum impl

- new job `hangar-e2e` in `.github/workflows/ci.yml`:
  ```yaml
  hangar-e2e:
    strategy:
      matrix:
        include:
          - target: aarch64-apple-darwin
            os: macos-latest
          - target: x86_64-unknown-linux-gnu
            os: ubuntu-latest
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
        with: { targets: '${{ matrix.target }}' }
      - name: install tmux
        run: |
          if [[ "${{ runner.os }}" == "macOS" ]]; then brew install tmux; fi
          if [[ "${{ runner.os }}" == "Linux" ]]; then sudo apt-get install -y tmux; fi
      - run: cargo test --workspace --all-targets --target ${{ matrix.target }}
      - run: cargo clippy --workspace --all-targets --target ${{ matrix.target }} -- -D warnings
  ```
- if any P0-P8 tripwire fails on either target — **fix here in P9.3, don't punt**. Likely failures: env-mutating tests without `ENV_LOCK` (`reference_env_lock_for_parallel_tests`), tmux-version drift, sqlx migration determinism

### REFACTOR

- cache `~/.cargo/registry` + `target/` per `(os, target)` key
- shard tripwires only if total runtime > 20 min on the slower runner (linux); below that, single-job is simpler

### Acceptance

- [ ] both matrix legs green on `main` branch
- [ ] tripwire 3 (meta count) green
- [ ] `scripts/hangar/run_all_tripwires.sh` green locally on macOS arm64
- [ ] zero `--ignored` tripwires (no skipped tests counted as "passing")
- [ ] CI lint via xtask wired as PR check
- [ ] bead closed
