# Phase P4 — Core 5 TUI Screens

**Weeks:** 9–10
**Bead:** `hangar:P4`
**Sub-beads:** 9 (P4.1 → P4.9)
**Blocks:** P5, P6, P7, P8, P9 (every later phase mutates these screens)
**Depends on:** P3 (plugin scaffold + 4 caps live: `event_stream_subscribe`,
`spawn_managed_subprocess`, `unix_socket_dial`, `secret_store_get`)
**Crate touched primarily:** `plugins/hangar-tui/ainb-plugin-hangar/`
**Wire crate touched:** `crates/ainb-hangar-proto`

## Goal

Ship 5 keyboard-driven Ratatui screens wired to daemon event streams.
No polling. Width-aware. Frosted progress banner. 80x24 minimum.
Every screen has unit reducer tests + tripwire. asciinema clip lands in PR.

## Locked decisions (consumed from build-plan.md)

- TUI is ainb plugin, not ainb-tui binary code. All P4 code lives under
  `plugins/hangar-tui/ainb-plugin-hangar/`.
- Daemon talk = JSON-RPC 2.0 over unix socket. Streaming via
  `host/event_stream_subscribe` cap.
- Persistence is daemon-side SQLite. Plugin holds zero domain data —
  pulls via RPC, caches in render-state reducer only.
- Determinism: HangarClock + IdGen injected from P0 fixtures. Tripwires
  use same harness.
- Style: Linear-tight density. Semantic tokens. Multica 5-color
  transcript taxonomy verbatim.

## Screen inventory (locked from UX research §12 + build-plan round 4)

|---|--------|--------|-----------------|

**Deliverable:**
```rust
pub enum HangarEvent {
    IssueCreated(IssueRow),
    IssueUpdated(IssueRow),
    IssueDeleted(IssueId),
    TaskQueued { task_id: TaskId, issue_id: IssueId, agent_id: AgentId },
    TaskStarted { task_id: TaskId, started_at: DateTime<Utc> },
    TaskProgress { task_id: TaskId, tool_calls: u32, elapsed_ms: u64 },
    TaskMessage { task_id: TaskId, kind: MessageKind, body: String },
    TaskFinished { task_id: TaskId, result: TaskResult, ended_at: DateTime<Utc> },
```

- `MessageKind` covers the 5-color taxonomy: `Agent | Thinking | ToolCall | ToolResult | Error`.
- `StreamClient` wraps `host/event_stream_subscribe`: open, parse JSON-RPC notification frames, push typed `HangarEvent` into mpsc.
- Reconnect-with-backoff (50ms / 200ms / 1s / 5s caps).
- Stream-id namespacing so multiple subscriptions don't cross-talk.

**RED tests:**

  `reference_msgpack_byte_determinism_vec_over_hashmap` — JSON here, but
  same determinism rule: `Vec<(K,V)>` not HashMap)
- `stream_decodes_progressive_partial_frames` (Content-Length framing
  arrives split across reads)
- `stream_reconnect_on_eof_replays_subscribe`
- `unknown_event_kind_returns_decode_err_doesnt_panic`

**GREEN:** minimal decode + mpsc forward.

**REFACTOR:** extract framing reader into trait so tripwires can fake
the socket.

**Acceptance:** every event variant has a round-trip golden; partial-read

## Risk register

| Risk | Severity | Mitigation |
|------|----------|------------|
| Tripwire flakiness from tmux paint timing | Med | adaptive sleep budget per `reference_vhs_sleep_budget`; substring not snapshot |
| Frosted banner re-renders cause flicker | Low | 1Hz tick channel, not 60Hz; double-buffer ratatui already handles |
| 5-color taxonomy unreadable on light-bg terminals | Med | terminal-bg detection via `termbg` crate; high-contrast fallback palette behind feature flag |
| Banner X-key conflicts with screen-local keybindings | Med | reserve capital X globally; document in `?` help overlay |
| Cross-screen navigation tripwire most likely to flake | Med | retry capture-pane poll up to 10x with 200ms gap |
| Settings keychain write leaks key into log on error path | High | `KeyMaterial` newtype with redacted `Debug`; clippy lint `dbg_macro` denied in this crate |

## Cross-cutting requirements (must-haves per screen)

- [ ] **Width-aware:** every screen recomputes layout from `area` on
      every render — `label_w / value_w / bar_w` pattern.
- [ ] **80x24 floor:** every screen passes a min-size smoke
      (`assert!(area.width >= 80 && area.height >= 24)` test).
- [ ] **Keyboard-first:** no mouse-required interaction.
- [ ] **Help overlay:** `?` shows screen-local + global hotkeys, near
      the control they affect (`feedback_keybinding_hints_near_control`).
- [ ] **No domain types in plugin:** all data comes from
      `ainb-hangar-proto` row structs; plugin owns zero SQLite refs
      (`project_ainb_plugin_owns_data_plane`).
- [ ] **`#[allow(dead_code)]` only with PR-ref TODO comment**
