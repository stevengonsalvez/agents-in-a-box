# Product

## Register

product

## Users

Fleet operators run multiple Claude and Codex sessions from a terminal. They
need fast situational awareness, precise attention handling, and safe control
without abandoning keyboard flow.

## Product Purpose

Agents in a Box coordinates AI coding sessions. Fleet is its authoritative
control surface: show every discovered session, surface asks and approvals,
then route exact versioned actions back to the provider.

## Brand Personality

Calm, exact, capable. It should feel like an operator cockpit, not a dashboard
or generic terminal skin.

## Anti-references

- Basic list-plus-detail terminal screens with flat hierarchy.
- Decorative SaaS dashboards, card grids, and fake telemetry.
- Color-only status meaning or controls that hide exact action consequences.

## Design Principles

- Attention first: actionable work must win visual hierarchy without hiding
  healthy sessions.
- Dense, never cramped: every column earns its place and full detail remains
  one keystroke away.
- Exact control: request identity, answer state, and delivery result stay
  visible through every action.
- Keyboard confidence: established Fleet bindings remain stable; new movement
  is local to the interview workbench.
- Honest degradation: cached, inferred, and managed state must look distinct.

## Accessibility & Inclusion

Keyboard-first operation. Meet WCAG AA contrast where terminal palettes allow,
never rely on color alone, render textual status labels, and avoid motion that
can obscure state changes.
